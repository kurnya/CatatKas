Privacy Policy

Terakhir diperbarui: 13 Juni 2026

1. Pendahuluan

CatatKas ("kami", "aplikasi") menghormati privasi Anda. Kebijakan ini menjelaskan bagaimana kami menangani informasi saat Anda menggunakan aplikasi CatatKas.

2. Data yang Kami Kumpulkan

CatatKas tidak mengumpulkan, mengirim, atau menyimpan data pribadi Anda ke server manapun.

Semua data yang Anda masukkan — termasuk transaksi, kategori, subkategori, dan metode pembayaran — disimpan secara lokal di perangkat Anda menggunakan localStorage browser.

3. Penyimpanan Data

  • Semua data transaksi disimpan di localStorage pada browser perangkat Anda.
  • Data tidak dikirim ke server, cloud, atau pihak ketiga manapun.
  • Data dapat dihapus kapan saja melalui fitur Reset di halaman Pengaturan aplikasi.
  • Menghapus data browser atau cache akan menghapus semua data aplikasi dari perangkat.

4. Layanan Pihak Ketiga

CatatKas di-host melalui GitHub Pages. GitHub dapat mengumpulkan data teknis standar seperti alamat IP dan informasi browser sesuai dengan GitHub Privacy Statement.

Aplikasi ini tidak menggunakan analitik, pelacakan, iklan, atau layanan pihak ketiga lainnya.

5. Offline & PWA

CatatKas dapat berjalan secara offline menggunakan teknologi Progressive Web App (PWA) dan Service Worker. Tidak ada data yang dikirim saat offline.

6. Keamanan Data

Karena data disimpan secara lokal di perangkat Anda, keamanan data bergantung pada keamanan perangkat dan browser Anda. Kami menyarankan untuk:

  • Menjaga perangkat tetap terkunci dengan PIN atau biometrik.
  • Melakukan backup data secara berkala melalui fitur Export JSON di Pengaturan.

7. Hak Anda

Anda memiliki kendali penuh atas data Anda:

  • Melihat semua data melalui halaman Transaksi.
  • Mengunduh cadangan data melalui Export JSON atau CSV.
  • Menghapus semua data melalui fitur Hapus Semua Transaksi atau Reset Master Data di Pengaturan.

8. Perubahan Kebijakan

Kami dapat memperbarui kebijakan ini dari waktu ke waktu. Perubahan akan ditampilkan di halaman ini dengan tanggal pembaruan terbaru.

9. Kontak

Jika Anda memiliki pertanyaan mengenai kebijakan privasi ini, Anda dapat menghubungi kami melalui repository GitHub: github.com/kurnya/CatatKas
