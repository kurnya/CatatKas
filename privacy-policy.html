Kebijakan Privasi CatatKas

Terakhir diperbarui: 13 Juni 2026

1. Pendahuluan

CatatKas ("kami", "aplikasi") menghormati dan menjunjung tinggi privasi Anda. Kebijakan Privasi ini menjelaskan secara transparun bagaimana aplikasi CatatKas memperlakukan data Anda saat menggunakan aplikasi ini.

Dengan menggunakan CatatKas, Anda menyetujui ketentuan yang dijelaskan dalam Kebijakan Privasi ini.

2. Informasi yang Tidak Kami Kumpulkan

CatatKas tidak mengumpulkan data pribadi Anda dalam bentuk apapun. Secara khusus:

  • CatatKas tidak memiliki fitur login atau pendaftaran akun pengguna.
  • CatatKas tidak mengumpulkan data pengguna ke server pengembang.
  • CatatKas tidak membagikan data pengguna ke pihak ketiga manapun.
  • CatatKas tidak menggunakan iklan dalam bentuk apapun.
  • CatatKas tidak menggunakan analytics, tracking, atau pelacakan perilaku pengguna.

3. Data yang Disimpan Secara Lokal

Seluruh data yang Anda masukkan di CatatKas disimpan secara lokal di perangkat Anda menggunakan fitur localStorage pada browser. Data yang disimpan meliputi:

  • Transaksi pemasukan dan pengeluaran;
  • Kategori;
  • Subkategori;
  • Metode pembayaran;
  • Preferensi aplikasi (mata uang, format tanggal, tema, dan pengaturan lainnya).
Pengembang tidak memiliki akses ke data transaksi atau catatan keuangan pengguna karena seluruh data disimpan secara lokal di perangkat pengguna.

4. Fitur Export dan Import Data

CatatKas menyediakan fitur Export JSON, Export CSV, dan Import JSON untuk keperluan backup dan pemulihan data. Ketentuan terkait fitur ini:

  • File hasil export dikelola sepenuhnya oleh pengguna.
  • CatatKas tidak mengunggah file backup ke server pengembang atau pihak ketiga manapun.
  • Pengguna bertanggung jawab penuh untuk menyimpan dan menjaga kerahasiaan file backup miliknya.

5. Penyimpanan dan Keamanan Data

  • Semua data disimpan di localStorage pada browser di perangkat Anda.
  • Data tidak dikirim ke server, cloud, atau pihak ketiga manapun.
  • Data dapat dihapus kapan saja melalui fitur di halaman Pengaturan aplikasi.
  • Menghapus data browser atau cache dapat menghapus semua data aplikasi dari perangkat.

Kami menyarankan Anda untuk:

  • Menjaga keamanan perangkat dengan PIN, pola, atau biometrik.
  • Melakukan backup data secara berkala melalui fitur Export JSON di Pengaturan.

6. Hak Pengguna

Anda memiliki kendali penuh atas seluruh data di dalam aplikasi CatatKas. Anda dapat:

  • Mengedit transaksi yang telah dicatat;
  • Menghapus transaksi satu per satu;
  • Menghapus semua transaksi sekaligus melalui fitur "Hapus Semua Transaksi" di Pengaturan;
  • Mereset master data (kategori, subkategori, dan metode pembayaran) ke kondisi bawaan melalui fitur "Reset Master Data" di Pengaturan;
  • Menghapus seluruh data aplikasi melalui pengaturan perangkat atau pengaturan browser (hapus data situs/clear site data).

7. Layanan Pihak Ketiga

CatatKas di-host melalui GitHub Pages. GitHub dapat mengumpulkan data teknis standar seperti alamat IP dan informasi browser sesuai dengan GitHub Privacy Statement.

Selain hosting, CatatKas tidak menggunakan layanan pihak ketiga lainnya — tidak ada SDK analitik, pelacakan, iklan, atau layanan pengumpulan data.

8. Mode Offline

CatatKas dapat berjalan secara offline menggunakan teknologi Progressive Web App (PWA) dan Service Worker. Seluruh fitur aplikasi berfungsi tanpa koneksi internet, dan tidak ada data yang dikirim keluar dari perangkat saat offline.

9. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Setiap perubahan akan ditampilkan di halaman ini beserta tanggal pembaruan terbaru. Kami menyarankan Anda untuk meninjau halaman ini secara berkala.
